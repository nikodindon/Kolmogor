# Project: Pong Game
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure with CSS and JavaScript
## Features
1. A paddle controlled by the left and right arrow keys on the keyboard.
2. A paddle controlled by the W and S keys on the keyboard.
3. A ball that bounces off the top, bottom, and side walls.
4. A scoring system that updates when a paddle misses the ball.
## Visual guidelines
- Background color: #000000 (black)
- Paddle color: #FFFFFF (white)
- Ball color: #FFFFFF (white)
- Scoreboard color: #FFFFFF (white)
- Interactive states: No specific interactive states required.
## Controls
- Left paddle: Left arrow key, Right arrow key
- Right paddle: W key, S key
## Technical constraints
- All CSS must be included within a <style> tag in the index.html file.
- All JavaScript must be included within a <script> tag in the index.html file.
- No external files or imports are allowed.
