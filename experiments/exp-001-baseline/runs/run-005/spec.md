# Project: Tetris Game
## Target
HTML and JavaScript
## Files
- `index.html` — HTML structure and canvas element
- `game.js` — Game logic and JavaScript functions
- `style.css` — Styling and visual guidelines
## Features
1. A 10x20 grid displayed on the canvas
2. The ability to move, rotate, and drop Tetriminos
3. Scoring system that increases with cleared lines
4. Game over condition when Tetriminos stack to the top
## Visual guidelines
- Background color: #000000
- Grid lines: #333333
- Tetrimino colors: 
  - I: #00FFFF
  - J: #0000FF
  - L: #FFA500
  - O: #FFFF00
  - S: #00FF00
  - T: #800080
  - Z: #FF0000
- Text color: #FFFFFF
- Font: Arial, sans-serif
## Controls
- Arrow keys for moving and rotating Tetriminos
- Spacebar for dropping Tetriminos
## Technical constraints
- Must be self-contained within a single HTML file
- No external dependencies allowed
- Must use either the canvas API or DOM for rendering
