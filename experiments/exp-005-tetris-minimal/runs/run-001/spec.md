# Project: Tetris Minimal
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure with CSS and JavaScript
## Features
1. Falling Tetris pieces
2. Left and right movement of pieces
## Visual guidelines
- Background color: #000000 (black)
- Tetris piece color: #00FF00 (green)
- Grid lines color: #FFFFFF (white)
## Controls
- Left arrow key — Move piece left
- Right arrow key — Move piece right
## Technical constraints
- All CSS must be within a <style> tag in `index.html`.
- All JavaScript must be within a <script> tag in `index.html`.
- No external files or imports are allowed.
