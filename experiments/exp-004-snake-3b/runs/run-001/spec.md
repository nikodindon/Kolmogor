# Project: Snake
## Target
JavaScript, single HTML file
## Files
- `index.html` — The root HTML file containing the game structure, including the game loop, event listeners, and game state.
## Features
1. The game starts with a snake of a specified length and moves in a predefined direction.
2. The snake consumes food items, increasing its length.
3. The snake cannot collide with the walls or itself, resulting in game over.
4. The game ends when the snake collides with the walls or itself.
## Visual guidelines
- Background color: #212121
- Snake body color: #FFD700
- Food color: #FF6F00
- Score text color: #FFD700
- Score background color: #212121
- Grid lines color: #444444
- Grid lines thickness: 1px
## Controls
1. Arrow keys to control the snake's direction.
2. Spacebar to pause/resume the game.
## Technical constraints
- All CSS must be included within a `<style>` tag in `index.html`.
- All JavaScript must be included within a `<script>` tag in `index.html`.
- No external files or imports are allowed.
