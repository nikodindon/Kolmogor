# Project: Asteroid Arcade Game
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure, CSS styles, and JavaScript logic
## Features
1. Player can move the spaceship left and right using the arrow keys.
2. Player can shoot asteroids using the spacebar.
3. Asteroids move across the screen in random directions.
4. Asteroids can be destroyed by shots, resulting in explosions.
5. Game ends when the spaceship is hit by an asteroid.
## Visual guidelines
- Background color: #000000 (black)
- Spaceship color: #00FF00 (green)
- Asteroid color: #FFFFFF (white)
- Explosion color: #FF0000 (red)
- Font: Arial, size 16px
- Interactive states: No specific states required
## Controls
- Left arrow key: Move spaceship left
- Right arrow key: Move spaceship right
- Spacebar: Shoot asteroid
## Technical constraints
- All CSS must be included within a <style> tag in `index.html`.
- All JavaScript logic must be included within a <script> tag in `index.html`.
- No external files or imports are allowed.
- The game must be contained within a single `index.html` file.
