# Project: Asteroid Arcade Game
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure and embedded CSS and JavaScript
## Features
1. Player can move the spaceship left and right using the arrow keys.
2. Player can shoot asteroids using the spacebar.
3. Asteroids move across the screen in random directions.
4. Asteroids split into smaller asteroids when hit by the player's shots.
5. Game ends when the player's spaceship is hit by an asteroid.
## Visual guidelines
- Background color: #000000 (black)
- Spaceship color: #00FF00 (green)
- Asteroid color: #FFFFFF (white)
- Bullet color: #FF0000 (red)
- Interactive states: No specific states required
## Controls
- Left arrow key: Move spaceship left
- Right arrow key: Move spaceship right
- Spacebar: Shoot bullet
## Technical constraints
- All CSS must be embedded within the <style> tag in index.html.
- All JavaScript must be embedded within the <script> tag in index.html.
- No external files or imports are allowed.
- The game must be contained within a single HTML file named index.html.
