# Project: Tetris Game
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure with CSS and JavaScript
## Features
1. A grid to display the Tetris pieces
2. Controls to move and rotate Tetris pieces
3. Scoring system to track the player's score
4. Game over condition when pieces stack up to the top
## Visual guidelines
- Background color: #000000
- Grid lines: #333333
- Tetris piece colors: 
  - I: #00FFFF
  - J: #0000FF
  - L: #FFA500
  - O: #FFFF00
  - S: #00FF00
  - T: #800080
  - Z: #FF0000
- Text color: #FFFFFF
- Game over text color: #FF0000
## Controls
- Arrow keys to move left, right, and down
- Up arrow key to rotate the piece
## Technical constraints
- All CSS must be within a <style> tag in index.html
- All JavaScript must be within a <script> tag in index.html
- No external files or imports allowed
