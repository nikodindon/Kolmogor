# Project: Tetris Game
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure with CSS and JavaScript
## Features
1. A grid to display the Tetris playing field.
2. A set of Tetriminos (I, J, L, O, S, T, Z) that can be rotated and moved.
3. A scoring system that updates as lines are cleared.
4. A game over condition when the Tetriminos stack up to the top of the grid.
5. A start and pause button to control the game.
## Visual guidelines
- Background color: #000000 (black)
- Grid lines: #FFFFFF (white)
- Tetrimino colors:
  - I: #00FFFF (cyan)
  - J: #0000FF (blue)
  - L: #FFA500 (orange)
  - O: #FFFF00 (yellow)
  - S: #00FF00 (green)
  - T: #800080 (purple)
  - Z: #FF0000 (red)
- Text color: #FFFFFF (white)
- Interactive states:
  - Button hover: #808080 (gray)
## Controls
- Arrow keys (left, right, down) to move Tetriminos.
- Up arrow key to rotate Tetriminos.
- Spacebar to drop Tetriminos quickly.
- P key to pause and resume the game.
## Technical constraints
- All CSS must be included within a `<style>` tag in `index.html`.
- All JavaScript must be included within a `<script>` tag in `index.html`.
- No external files or imports are allowed.
