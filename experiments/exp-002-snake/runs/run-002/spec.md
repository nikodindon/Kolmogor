# Project: Snake Game
## Target
JavaScript — single_html
## Files
- `index.html` — HTML structure with CSS and JavaScript
## Features
1. The snake moves continuously in one direction.
2. The snake grows in length when it eats food.
3. The game ends when the snake collides with the walls or itself.
4. The score is displayed on the screen.
## Visual guidelines
- Background color: #000000
- Snake color: #00FF00
- Food color: #FF0000
- Score color: #FFFFFF
- Font: Arial, sans-serif
- Interactive states: No specific states required
## Controls
- Arrow keys to change the direction of the snake
## Technical constraints
- All CSS must be included within a <style> tag in index.html.
- All JavaScript must be included within a <script> tag in index.html.
- No external files or imports are allowed.
